# Frontend

React + Tailwind: player UI (text client) and admin interface

This is a unit of the **LoFP** project.

## Sibling Units

- **Engine** (`engine`) — Go backend: script parser, game engine, command interpreter, MongoDB persistence
- **Scripts** (`original`) — Original game script files and documentation (read-only reference)

The orchestrator CLAUDE.md at the project root (`../CLAUDE.md`) coordinates cross-unit concerns.
